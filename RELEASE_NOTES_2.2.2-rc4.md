# ЭВО.СНТ S3 2.2.2-rc4

Промежуточный тестовый релиз для проверки исправлений регистрации и heartbeat агентов распределённого нагрузочного тестирования перед выпуском стабильной версии 2.2.2.

## Основное исправление

### PR #91 — Fix agent heartbeat failure when agent name is missing

- исправлена ошибка HTTP 500 при `GET /api/agents`, если зарегистрированный агент не передал `name`;
- исправлено нарушение heartbeat для агента без имени;
- сортировка зарегистрированных агентов сделана null-safe;
- отсутствие имени агента больше не приводит к `NullPointerException` в `AgentRegistry.list()`;
- добавлен regression-тест регистрации агента без имени;
- тест подтверждает корректное получение списка агентов и последующий heartbeat.

## Изменения предыдущих RC

Версия включает исправления и доработки предыдущих 2.2.2 release candidates, включая:

- поддержку распределённых S3-тестов и регистрацию агентов;
- исправления CSP и состояний загрузки страницы `/distributed-tests`;
- исключение OFFLINE/DISABLED агентов из выбора;
- timeout API-запросов и корректную обработку ошибок;
- интерактивные графики производительности;
- автоматическую загрузку сохранённых заданий;
- исправления prerelease workflow и публикации release assets.

## Что проверить

1. Запустить координатор версии `2.2.2-rc4`.
2. Запустить агент с настроенными coordinator URL и registration token.
3. Проверить успешную регистрацию агента.
4. Проверить `GET /api/agents`: HTTP 200, без Internal Server Error.
5. Проверить обновление поля последней активности агента при heartbeat.
6. Повторить регистрацию/heartbeat агента без явно заданного имени и убедиться, что HTTP 500 не возникает.
7. Открыть `/agents` и убедиться, что список зарегистрированных агентов отображается корректно.
8. Открыть `/distributed-tests`, выбрать доступный агент и выполнить распределённый S3-тест.
9. Проверить корректное завершение теста и отображение агрегированной статистики.
10. Проверить локальные тесты и основные функции предыдущих RC на отсутствие регрессий.

## Статус

Версия `2.2.2-rc4` предназначена для функционального и приёмочного тестирования исправлений распределённого режима. После успешного тестирования может быть подготовлена стабильная версия `2.2.2`.
