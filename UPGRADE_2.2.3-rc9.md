# Обновление до 2.2.3-rc9

1. Остановите текущий экземпляр приложения.
2. Замените JAR или Docker image на версию `2.2.3-rc9`.
3. Сохраните существующий bootstrap-файл и каталог конфигурации без изменений.
4. Запустите приложение.
5. Откройте `/settings`, выберите любой вариант представления A/B/C/D.
6. Перейдите в `/settings/keycloak` и убедитесь, что выбранный вариант UI сохранился и страница оформлена в общем корпоративном стиле.
7. Проверьте функции «Проверить подключение» и «Сохранить» Keycloak.

Миграции БД и изменения конфигурационного формата для этого RC не требуются.
