# ЭВО.СНТ S3 2.2.0

Релиз 2.2.0 развивает стабильную ветку 2.1.x и включает исправления Web UI, усиление bootstrap-режима, новый Health Dashboard и локальные шаблоны заданий.

## Новые возможности

### Мониторинг

- новый раздел `/monitoring`;
- REST endpoint `GET /api/health/overview`;
- состояние приложения, PostgreSQL, Vault, S3 и Keycloak;
- uptime и время последней проверки;
- ручное и автоматическое обновление каждые 30 секунд.

### Сохранённые задания

- сохранение параметров теста под пользовательским названием;
- загрузка, обновление и удаление шаблонов;
- локальное хранение в браузере;
- Access Key и Secret Key не сохраняются.

## Улучшения

- единый центр настроек и улучшенная диагностика PostgreSQL/Vault;
- канонические маршруты Web UI без обязательного `.html`;
- старые адреса сохранены через redirect;
- выпадающий список S3-бакетов с сортировкой и явным выбором;
- исправлена CSP-совместимость страницы агентов;
- улучшены состояния загрузки, ошибки и тайм-ауты UI.

## Bootstrap

- отсутствующий, пустой или whitespace-only bootstrap-файл не блокирует запуск;
- повреждённый непустой JSON диагностируется явно;
- перед заменой конфигурации создаётся резервная копия;
- применяется атомарная запись с безопасным fallback.

## Возможности 2.1.0, сохранённые без изменений

- REST API v2;
- расширенные Grafana dashboards и Prometheus alerts;
- Vault AppRole;
- управление агентами;
- сравнение запусков и тренды;
- экспорт HTML/PDF;
- защищённый импорт/экспорт `.evos3`.

## Совместимость

- Java 21+;
- PostgreSQL 15–18;
- совместимость с конфигурацией 2.1.x;
- миграция PostgreSQL для обновления с 2.1.0 не требуется.

Перед обновлением ознакомьтесь с `UPGRADE_2.2.0.md`.
