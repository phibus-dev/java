# ЭВО.СНТ Performance 2.2.3-rc6

## Исправления

- Исправлена пустая область графиков в разделе «Тренды производительности» при наличии рассчитанной сводки.
- Отрисовка графиков теперь выполняется после того, как скрытая панель трендов стала видимой и браузер завершил расчёт layout.
- Добавлена дополнительная перерисовка canvas на следующем animation frame.
- `PerformanceChart` больше не зависит жёстко от наличия `ResizeObserver`: при его отсутствии используется обработчик `window.resize`.
- Добавлен regression test для отрисовки трендов после открытия скрытой панели и fallback без `ResizeObserver`.

## Совместимость

- Новые миграции PostgreSQL отсутствуют.
- API и формат сохранённых результатов тестов не изменены.
- Исправление относится к Coordinator/Web UI; агенты можно оставить на совместимой версии.

Базовая функциональность соответствует 2.2.3-rc5 с исправлением визуализации трендов производительности.
