# Обновление ЭВО.СНТ S3 до 2.2.1

## Назначение

Версия 2.2.1 исправляет ошибку запуска версии 2.2.0, связанную с созданием `BootstrapSettingsStore`.

## Порядок обновления

1. Остановите приложение.
2. Сохраните резервную копию каталога `config` и файла `bootstrap-settings.json`.
3. Замените JAR-файл на `evo-snt-s3-2.2.1.jar` либо обновите Docker image до тега `2.2.1`.
4. Запустите приложение.
5. Проверьте `/actuator/health/readiness` и открытие `/settings`.

## Миграции

- миграция PostgreSQL не требуется;
- формат bootstrap-конфигурации не изменён;
- настройки Vault, Keycloak и S3-профилей сохраняются без изменений.

## Откат

Для отката остановите приложение и верните предыдущий JAR или Docker image. Конфигурационные файлы совместимы с 2.2.0.
