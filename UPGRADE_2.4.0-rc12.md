# Upgrade / test guide — 2.4.0-rc12

1. Разверните JAR или Docker image 2.4.0-rc12 поверх rc11.
2. Новых миграций БД относительно rc11 нет.
3. После обновления выполните полную перезагрузку страницы браузера.
4. Запустите Kafka M3 Replication Test для существующего topic: задание должно создаться без ошибки JDBC timestamp.
5. Успешный Replication Test должен завершиться статусом `COMPLETED` и показать partitions, under-replicated, offline и min ISR violations.
6. При использовании Kafka M4 Failover проверьте сохранение времени запуска, завершения, обнаружения отказа и восстановления.
7. Откройте историю Kafka Producer и Consumer/Throughput: на странице должно отображаться не более 10 строк.
8. Проверьте переходы `Назад` и `Вперёд`, номер страницы и общее количество записей.
9. Повторите проверку для Kafka M3, M4 и истории ClickHouse.

При сохранении ошибки Replication Test используйте диагностическое сообщение под Runtime: начиная с rc11 сервер возвращает фактическую первопричину.
