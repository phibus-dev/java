# ЭВО.СНТ Performance 2.2.3-rc5

## Исправления

- Исправлено отображение зарегистрированных ONLINE-агентов на странице «Распределённые тесты».
- UI теперь корректно читает capability агента из `tags.capabilities`, как их возвращает `/api/agents`.
- Сохранена обратная совместимость с форматом `agent.capabilities`.
- Capability нормализуются в верхний регистр, поэтому значения `S3` и `CLICKHOUSE` корректно участвуют в фильтрации.
- Добавлен regression test для случая `tags.capabilities=S3,CLICKHOUSE`.

## Совместимость

- Новые миграции PostgreSQL отсутствуют.
- Формат регистрации и heartbeat агентов не изменён.
- Обновление требуется прежде всего для Coordinator/UI; уже зарегистрированные агенты после обновления Coordinator должны начать отображаться без повторной регистрации.

Базовая функциональность соответствует 2.2.3-rc4 с исправлением фильтрации capability агентов.
