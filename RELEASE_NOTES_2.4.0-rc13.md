# ЭВО.СНТ S3 2.4.0-rc13

Тринадцатый release candidate версии 2.4.0.

## Изменения относительно rc12

### Единая шапка приложения
- шапка всех страниц приведена к единой сетке и одинаковому форматированию;
- длинные заголовки Kafka и других разделов больше не смещают логотип, версию, поиск и профиль пользователя;
- логотип ПАО «Транснефть» и название платформы отображаются единым вертикальным блоком;
- сохранена адаптивная компоновка для узких экранов;
- переход по логотипу ведёт на главную страницу.

### Отображение версии
- версия приложения добавляется в модель всех серверных страниц централизованно;
- `/api/session` использует тот же источник версии;
- исключён вывод `Версия null` и `Версия undefined`;
- версия выводится на страницах Kafka и в меню пользователя;
- URL общих CSS и JavaScript обновлены для принудительного обновления браузерного кэша.

### Проверки
- добавлены регрессионные тесты получения версии;
- добавлена проверка единого подключения ресурсов шапки во всех HTML-шаблонах.

## Совместимость

Новых миграций БД относительно rc12 нет. Существующие профили, задания и история запусков сохраняются.
