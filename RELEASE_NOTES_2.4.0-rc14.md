# ЭВО.СНТ S3 2.4.0-rc14

Четырнадцатый release candidate версии 2.4.0.

## Изменения относительно rc13

### Регистрация и авторизация агентов
- межсервисная авторизация агента переведена со стандартного `Authorization: Bearer` на отдельный заголовок `X-Agent-Token`;
- исключена обработка agent token механизмом пользовательской OIDC/JWT-аутентификации координатора;
- heartbeat, получение заданий и передача статистики больше не получают ошибку `401` из-за формата agent token;
- координатор сохраняет поддержку старого Bearer-заголовка для обратной совместимости.

### Защита от повторных регистраций
- повторная регистрация агента с одинаковыми именем, hostname и адресом повторно использует существующие UUID и token;
- циклические ошибки авторизации больше не создают новые строки в списке агентов;
- при повторной регистрации обновляются версия, ресурсы, capabilities и время последней активности;
- добавлены регрессионные тесты заголовка авторизации и идемпотентной регистрации.

## Совместимость

Новых миграций БД относительно rc13 нет. Для устранения ошибки необходимо обновить как координатор, так и agent JAR.
