# Обновление до ЭВО.СНТ S3 2.2.2-rc1

Это промежуточный тестовый релиз.

## Требования

- Java 21+
- существующая конфигурация 2.2.1 совместима;
- миграции PostgreSQL не требуются;
- изменения bootstrap-settings.json не требуются.

## Обновление JAR

1. Остановить приложение.
2. Сохранить резервную копию текущего JAR 2.2.1.
3. Установить `evo-snt-s3-2.2.2-rc1.jar`.
4. Запустить приложение с прежней конфигурацией.
5. Выполнить smoke-test страниц `/tasks` и `/history`.

## Откат

Для отката остановите приложение и верните JAR версии 2.2.1. Изменения схемы данных отсутствуют, поэтому дополнительный rollback не требуется.
