# Обновление до ЭВО.СНТ Performance 2.2.3-rc4

Версия 2.2.3-rc4 добавляет явную поддержку макроса `{shard}` в Keeper path для ReplicatedMergeTree.

## Порядок обновления

1. Остановить текущий экземпляр приложения.
2. Сохранить резервную копию конфигурации и PostgreSQL.
3. Заменить JAR на `evo-snt-s3-2.2.3-rc4.jar` либо Docker image на тег `2.2.3-rc4`.
4. Запустить приложение и открыть раздел `ClickHouse → Failover`.
5. Проверить путь подготовки таблицы: `/clickhouse/tables/{shard}/evo_snt_perf_replica`.

## Важно

- Обновление не меняет Keeper paths существующих таблиц.
- Чтобы применить новый путь к тестовой таблице, включите `DROP существующей таблицы перед созданием` и выполните создание повторно.
- Макрос `{replica}` продолжает использоваться как имя реплики.
- Новые миграции базы данных отсутствуют; откат к rc3 не требует отката схемы PostgreSQL.
