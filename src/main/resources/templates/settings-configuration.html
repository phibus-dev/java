Экспорт

Для экспорта секретов шифрование обязательно. Используется AES-256-GCM и PBKDF2-HMAC-SHA256.

Импорт

Выберите JSON или зашифрованный файл .evos3

Перед импортом автоматически создаётся резервная копия bootstrap-файла. Для применения PostgreSQL и Keycloak потребуется перезапуск.
