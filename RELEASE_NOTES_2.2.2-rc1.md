# ЭВО.СНТ S3 2.2.2-rc1

Промежуточный тестовый релиз для проверки последних изменений Web UI перед выпуском стабильного patch-релиза.

## Включённые изменения

### PR #71 — Professional performance charts
- полноценные оси X/Y и единицы измерения на графиках;
- автоматический шаг шкалы и сетка;
- интерактивные tooltips;
- легенда и несколько серий;
- HiDPI/Retina и адаптивная перерисовка;
- текущая и средняя скорость в live-графике;
- Throughput, OPS, Errors и p50/p95/p99 в трендах производительности.

### PR #72 — Saved test preset loading
- сохранённое задание автоматически применяется при выборе;
- корректный порядок восстановления profile/scenario и зависимых полей;
- синхронизация bucket selector;
- Access key и Secret key по-прежнему не сохраняются и очищаются при загрузке.

## Назначение

Релиз предназначен только для функционального тестирования. Для промышленной эксплуатации используйте стабильный релиз 2.2.1 до завершения проверки.

## Что проверить

1. Запустить UPLOAD/DOWNLOAD тест и проверить оси, сетку, подписи и tooltip графика.
2. На странице истории построить тренды по 2–20 запускам и проверить Throughput, OPS, p50/p95/p99 и Errors.
3. Сохранить тестовое задание, изменить форму вручную, затем выбрать сохранённое задание и убедиться, что параметры восстанавливаются автоматически.
4. Проверить, что Access key и Secret key после загрузки сохранённого задания остаются пустыми.
