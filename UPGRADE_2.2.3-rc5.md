# Обновление до ЭВО.СНТ Performance 2.2.3-rc5

Версия 2.2.3-rc5 исправляет фильтрацию агентов на странице «Распределённые тесты».

## Порядок обновления

1. Остановить Coordinator версии 2.2.3-rc4.
2. Сохранить резервную копию конфигурации и PostgreSQL.
3. Заменить JAR на `evo-snt-s3-2.2.3-rc5.jar` либо Docker image на тег `2.2.3-rc5`.
4. Запустить Coordinator и открыть раздел `Агенты` — агент должен иметь статус `ONLINE`.
5. Открыть `Распределённые тесты`, выбрать движок `S3` или `CLICKHOUSE` и убедиться, что агент с соответствующей capability появился в списке.

## Важно

- Перерегистрировать существующие агенты не требуется.
- Версия агента 2.2.3-rc4 совместима с Coordinator 2.2.3-rc5 для данного исправления.
- Новые миграции базы данных отсутствуют; откат Coordinator к rc4 не требует отката схемы PostgreSQL.
