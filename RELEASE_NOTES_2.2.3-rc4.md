# ЭВО.СНТ Performance 2.2.3-rc4

## Изменения

- Keeper path по умолчанию для ReplicatedMergeTree изменён на `/clickhouse/tables/{shard}/evo_snt_perf_replica`.
- В форме подготовки ReplicatedMergeTree явно указана поддержка макросов `{shard}` и `{replica}`.
- Сохранена возможность вручную задать собственный Keeper path и имя реплики.

## Совместимость

- Новые миграции PostgreSQL отсутствуют.
- Существующие таблицы и Keeper paths автоматически не изменяются.
- Для уже созданных таблиц изменение пути требует пересоздания таблицы с включённым параметром `DROP`.
