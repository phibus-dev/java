# S3 Performance Test Web 2.0.4

Patch release исправляет обработку CSRF на основной странице Web UI.

## Исправлено

- устранён `403 Forbidden` при выполнении `POST /api/buckets`;
- устранён `403 Forbidden` при запуске теста через `POST /api/tests`;
- устранён `403 Forbidden` при отмене теста через `POST /api/tests/{id}/cancel`;
- добавлен общий модуль `csrf-fetch.js`, автоматически добавляющий CSRF-заголовок для same-origin запросов `POST`, `PUT`, `PATCH` и `DELETE`;
- для изменяющих запросов автоматически используется `credentials: same-origin`;
- главная страница теперь публикует CSRF token и имя заголовка через meta-теги;
- исправлена устаревшая подпись `Web 1.3` на `Web 2.0`.

## Совместимость

Релиз полностью совместим с конфигурацией и схемой PostgreSQL версии 2.0.3. Дополнительные миграции базы данных не требуются.

## Проверка после обновления

1. Открыть главную страницу приложения.
2. Нажать «Получить бакеты».
3. Убедиться, что список бакетов загружается без ответа `403 Forbidden`.
4. Запустить тест и проверить создание задания.
5. Отменить длительный тест и проверить статус `CANCELLED`.
