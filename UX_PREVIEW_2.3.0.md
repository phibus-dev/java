# UX Preview 2.3.0

Тестовая ветка для оценки применимости изменений перед включением в релиз 2.3.0.

## Реализовано

- Главная титульная страница `/` в гибридном формате: назначение сервиса, состояние, модули, быстрый поиск, последние действия и build-info.
- Глобальная пользовательская панель: имя, роль, версия, кнопка выхода.
- POST logout с CSRF token.
- Favicon SVG и web app manifest.
- Breadcrumbs на вложенных страницах.
- Глобальный поиск с переходом в историю и фильтрацией таблиц истории по параметру `search`.
- Toast notifications как единый UI-механизм обратной связи.
- Role-aware UI: отображение роли и базовое ограничение изменяющих действий для VIEWER; поддержка `data-min-role` для точной разметки.
- Сводный status-блок на главной. Состояния не представляются зелёными без подтверждения: Keycloak показывает ENABLED/NOT CONFIGURED, S3/ClickHouse/Agents дают навигационный статус до подключения специализированных health probes.
- Быстрые переходы S3 / ClickHouse / Agents / Monitoring / Keycloak.
- Информация о версии и времени запуска через `/api/session`.
- Сохранены четыре режима UI A/B/C/D.

## Критерии оценки

1. `/` открывается как стартовая страница и даёт доступ ко всем ключевым модулям.
2. Пользователь и роль корректно отображаются после входа через Keycloak Client Roles.
3. Кнопка «Выйти» завершает локальную Spring Security session.
4. Favicon отображается на вкладке браузера.
5. Переключение A/B/C/D сохраняется между разделами.
6. Breadcrumbs корректно отражают текущий маршрут.
7. VIEWER не может инициировать основные изменяющие действия из UI; backend RBAC остаётся главным уровнем защиты.
8. Глобальный поиск переносит запрос в историю и фильтрует строки по содержимому.
9. Главная страница адаптивна на ширине desktop/tablet/mobile.
10. Ни один неподключённый компонент не обозначается как OK без реального подтверждения.

## Следующий этап после UX-оценки

Перед включением в релиз рекомендуется добавить специализированный backend endpoint агрегированного health-state для S3, ClickHouse, Keeper, Keycloak и Agents, чтобы главный dashboard показывал не навигационные статусы, а реальные `OK / DEGRADED / UNAVAILABLE / NOT CONFIGURED`.
