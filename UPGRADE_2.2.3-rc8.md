# Обновление до 2.2.3-rc8

## Перед обновлением

1. Сохраните текущий `bootstrap-settings.json` и резервную копию PostgreSQL приложения.
2. Остановите текущий процесс приложения перед заменой executable JAR.
3. Проверьте SHA-256 скачанного RC8 по файлу `SHA256SUMS`.

## Установка JAR

Замените текущий JAR на `evo-snt-s3-2.2.3-rc8.jar` и запустите приложение штатным способом.

## База данных

При переходе с более раннего RC будут автоматически применены существующие Flyway-миграции, включая хранение подробной shard-aware диагностики Replicated tests.

## Новый UI

После входа в приложение над рабочими панелями отображается переключатель **«Вариант представления»**. Доступны режимы A/B/C/D. Выбор сохраняется в `localStorage` браузера; серверная конфигурация для этого не требуется.

Если требуется сбросить выбранный режим, удалите ключ `evo-snt-ui-view` из Local Storage браузера либо выберите вариант A.

## Проверка после обновления

- открыть `/tasks` и переключить A/B/C/D;
- перейти в `/clickhouse`, `/monitoring`, `/agents`, `/settings` и убедиться, что выбранный режим сохраняется;
- открыть детальную историю Replicated test и проверить корректность таблицы консистентности;
- выполнить один S3 и один ClickHouse тест и проверить сохранение результата в истории.
