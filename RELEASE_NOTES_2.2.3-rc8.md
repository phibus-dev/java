# ЭВО.СНТ S3 2.2.3-rc8

Release candidate с новым переключаемым корпоративным UI.

## UI

- Добавлены четыре варианта представления интерфейса:
  - **A — Карточный**: основной рекомендуемый режим;
  - **B — Информационные блоки**: плоская компоновка с акцентом на показатели;
  - **C — Компактный**: уменьшенные отступы и повышенная плотность информации;
  - **D — Табличный фокус**: максимально компактное представление для анализа больших наборов метрик.
- Выбранный вариант сохраняется в браузере (`localStorage`) и применяется при переходах между основными разделами.
- Обновлена визуальная система в стилистике ПАО «Транснефть»: сине-белая основа, красные акценты, строгая типографика, унифицированные карточки, таблицы и статусы.
- Новый UI применён к основным страницам S3, истории, ClickHouse, Replicated tests и детальной истории, распределённым тестам, агентам, мониторингу и настройкам.

## ClickHouse / Replicated tests

RC8 включает накопленные изменения RC7: сохранение длительности и ошибок заданий, объединённую историю ClickHouse, тип теста, runtime progress для Replicated tests, локализованные названия метрик, shard-aware проверку консистентности и подробную диагностику по репликам.

## Совместимость

- API и схема существующих S3/ClickHouse заданий не меняются из-за UI-переключателя.
- Выбор режима представления хранится только в браузере и не требует миграции БД.
- AWS SDK BOM: 2.53.1.
