# ЭВО.СНТ Performance 2.2.3-rc2

Второй release candidate стабилизирует ClickHouse-функции, добавленные в 2.2.3-rc1.

## Исправления

- запуск ClickHouse-теста фиксируется в PostgreSQL до передачи в фоновый executor;
- итоговый статус и метрики сохраняются до перезагрузки страницы истории;
- при невозможности создать запись истории тест не запускается без фиксации результата;
- ошибка сохранения replication snapshot не блокирует отображение собранного состояния;
- ошибка публикации Micrometer-метрик не обрывает Replication API;
- Replicated* и Failover-сценарии используют отдельный executor и не конкурируют с обычными тестами;
- отказ постановки сценария в очередь фиксируется со статусом `FAILED`;
- API и Web UI отображают первопричину ошибки вместо общего HTTP 500.

## Проверки

- Maven `clean verify`;
- CodeQL;
- Dependency Review;
- regression-тесты сохранения истории, Replication API и запуска workflow;
- JavaScript syntax checks для изменённых страниц.

## Совместимость

- миграции PostgreSQL не добавляются: используются V9–V13 из 2.2.3-rc1;
- конфигурация, профили и история 2.2.3-rc1 совместимы без преобразования;
- Coordinator и Agents рекомендуется обновлять совместно;
- Java 21 остаётся целевой версией runtime.
