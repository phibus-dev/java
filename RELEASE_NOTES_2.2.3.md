# ЭВО.СНТ S3 2.2.3

Стабильный выпуск 2.2.3 сформирован по результатам серии release candidate и подтверждённого функционального тестирования.

## Основные изменения

- Сохранение результатов выполненных нагрузочных тестов и расширенная история заданий.
- Детализация истории ClickHouse: ошибки, длительность, метрики и тип теста.
- Объединение истории обычных и Replicated ClickHouse tests.
- Runtime-прогресс Replicated tests и уточнённые русские наименования метрик репликации.
- Улучшенная проверка консистентности ReplicatedMergeTree.
- Failover Scenario и HA Dashboard для ClickHouse.
- Поддержка `{shard}` и `{replica}` в Keeper path.
- Корпоративный UI и переключаемые варианты представления для основных разделов, включая Replication, HA Dashboard, Failover и настройки Keycloak.
- Исправления мониторинга и отображения состояния внешних сервисов.
- Интеграция Keycloak/OpenID Connect с Client Roles клиента приложения.
- Исправлена обработка CSRF для проверки и сохранения настроек Keycloak.
- Client Roles читаются из `resource_access.<client-id>.roles`; поддерживаются роли `ADMIN`, `OPERATOR`, `VIEWER`.

## Keycloak

Для клиента приложения (например, `s3-perf`) создайте client roles `ADMIN`, `OPERATOR`, `VIEWER` и назначайте их пользователям через Role mapping. После изменения ролей необходимо выполнить повторный вход, чтобы получить новый токен.

## Статус

Версия 2.2.3 является стабильным выпуском после подтверждения устранения и тестирования выявленных ошибок в release candidate 2.2.3-rc12.
