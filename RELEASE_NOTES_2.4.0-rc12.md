# ЭВО.СНТ S3 2.4.0-rc12

Двенадцатый release candidate версии 2.4.0.

## Изменения относительно rc11

### Kafka M3 и M4
- исправлена запись времени запуска и завершения тестов в PostgreSQL;
- `java.time.Instant` преобразуется в совместимый с PostgreSQL JDBC тип `OffsetDateTime`;
- Replication Test больше не завершается ошибкой `Can't infer the SQL type to use for an instance of java.time.Instant`;
- аналогичное исправление применено к Kafka M4 Failover для времени запуска, завершения, обнаружения отказа и восстановления;
- добавлен регрессионный тест JDBC timestamp bindings.

### Пагинация истории
- пагинация запускается независимо от завершения запроса `/api/session`;
- на каждой странице истории отображается не более 10 записей;
- явная пагинация добавлена для Kafka Producer, Consumer/Throughput, M3 и M4;
- пагинация добавлена для общей истории ClickHouse, Replicated и Failover;
- динамические Kafka-таблицы обновляют paginator сразу после получения данных;
- скрытие строк защищено от переопределения стилями представления;
- общий UI-скрипт получил версионированный URL для обновления браузерного кэша;
- добавлены регрессионные проверки покрытия таблиц истории.

## Совместимость

Новых миграций БД относительно rc11 нет. Существующие Kafka-профили и история запусков сохраняются.
