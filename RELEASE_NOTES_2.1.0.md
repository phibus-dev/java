# ЭВО.СНТ S3 2.1.0

Релиз 2.1.0 развивает стабильную линию 2.0.5 и добавляет функции промышленной эксплуатации, распределённого управления и анализа производительности.

## Основные изменения

- корпоративный Web UI «ЭВО.СНТ S3» с разделами «Задания», «История», «Агенты» и «Настройки»;
- завершённая поддержка Vault AppRole: кеширование и renewal token, автоматический повторный login после 401/403, TLS и пользовательский CA;
- управление жизненным циклом агентов: включение, отключение, отзыв identity, повторная регистрация и запрос обновления версии;
- сравнение 2–20 запусков и построение трендов throughput, OPS, latency, ошибок и длительности;
- экспорт результатов тестов в автономный HTML и PDF;
- расширенные Grafana dashboards и Prometheus alert rules;
- защищённый импорт и экспорт конфигурации приложения;
- формат `.evos3` с AES-256-GCM и PBKDF2-HMAC-SHA256;
- автоматическая резервная копия bootstrap-конфигурации перед импортом;
- актуализированные release workflow, Docker image и документация.

## Совместимость

- Java 21+;
- PostgreSQL 15–18;
- HashiCorp Vault Community Edition 2.0.x;
- Kubernetes 1.28+;
- AWS S3, MinIO и другие S3-совместимые хранилища.

Bootstrap-конфигурации 2.0.x поддерживаются. Перед обновлением рекомендуется создать резервную копию bootstrap-файла и PostgreSQL.

## Проверка после установки

1. Проверить `/actuator/health/readiness`.
2. Открыть `/settings` и проверить PostgreSQL, Vault и Keycloak.
3. Проверить список S3-профилей и получение бакетов.
4. Выполнить локальный тест.
5. Зарегистрировать агент и выполнить распределённый тест.
6. Проверить историю, тренды и экспорт HTML/PDF.
7. Импортировать dashboards и проверить `/actuator/prometheus`.
8. Выполнить тестовый экспорт конфигурации без секретов и зашифрованный экспорт `.evos3`.
