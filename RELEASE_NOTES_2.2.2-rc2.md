# ЭВО.СНТ S3 2.2.2-rc2

Промежуточный тестовый релиз для проверки исправления распределённых тестов из PR #75 перед выпуском стабильной версии 2.2.2.

## Основное исправление

### PR #75 — Distributed tests CSP and loading states

- JavaScript страницы `/distributed-tests` вынесен из inline `<script>` в отдельный `distributed-tests.js`;
- страница совместима с действующей CSP `script-src 'self'`;
- подключён общий `csrf-fetch.js` для защищённых POST-запросов;
- устранено бесконечное состояние `Загрузка…` для списка агентов и истории распределённых запусков;
- добавлены явные состояния загрузки, отсутствия данных и ошибок;
- добавлен timeout запросов 10 секунд через `AbortController`;
- кнопка ручного обновления блокируется на время запроса;
- агенты со статусом `OFFLINE` и `DISABLED` исключаются из выбора;
- polling истории приостанавливается для скрытой вкладки и очищается при уходе со страницы;
- сохранены создание распределённых тестов и периодическое обновление истории;
- добавлены regression-тесты CSP, loading/empty/error/timeout состояний.

## Изменения, уже включённые в 2.2.2-rc1

- профессиональные интерактивные графики производительности;
- полноценные шкалы, сетка, tooltips и p50/p95/p99;
- автоматическая загрузка сохранённых заданий;
- исправление prerelease workflow и публикации release assets.

## Что проверить

1. Открыть `/distributed-tests` и убедиться, что состояния загрузки сменяются данными либо понятным пустым состоянием.
2. При отсутствии доступных агентов проверить сообщение `Нет доступных агентов`.
3. При пустой истории проверить сообщение `Распределённые запуски отсутствуют`.
4. Смоделировать недоступность API и убедиться, что максимум через 10 секунд отображается ошибка.
5. Зарегистрировать агент, выбрать его и запустить распределённый S3-тест.
6. Проверить обновление агрегированной статистики и истории.
7. Убедиться, что в DevTools Console отсутствуют CSP-ошибки.
8. Повторно проверить локальные тесты, историю и графики из rc1.

## Статус

Версия `2.2.2-rc2` предназначена только для функционального и приёмочного тестирования. Для промышленной эксплуатации до завершения проверки используйте стабильную версию `2.2.1`.
