# Обновление до ЭВО.СНТ Performance 2.2.3-rc1

Версия 2.2.3-rc1 развивает существующий S3-инструмент в сторону универсальной платформы нагрузочного тестирования.

## Требования

- Java 21+;
- существующая конфигурация 2.2.2 сохраняется;
- Coordinator и Agent рекомендуется обновлять совместно;
- перед обновлением сохранить резервную копию JAR и конфигурации.

## Обновление

1. Остановить Coordinator и Agents.
2. Заменить JAR на `evo-snt-s3-2.2.3-rc1.jar` либо использовать Docker image с тегом `2.2.3-rc1`.
3. Запустить Coordinator и проверить readiness.
4. Запустить Agents и проверить регистрацию/heartbeat.
5. Выполнить существующий локальный и распределённый S3-тест для контроля обратной совместимости.

## Особенности RC1

Начальный этап 2.2.3-rc1 не требует миграции существующих S3-профилей. Новые архитектурные сущности test engine вводятся с сохранением поведения S3. ClickHouse-функциональность будет добавляться последующими PR в рамках этой release-ветки.

## Откат

При необходимости вернуть JAR/Docker image версии 2.2.2 и предыдущую конфигурацию. До появления миграций ClickHouse отдельный rollback данных не требуется.
