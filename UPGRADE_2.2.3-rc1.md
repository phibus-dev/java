# Обновление до ЭВО.СНТ Performance 2.2.3-rc1

Версия 2.2.3-rc1 развивает существующий S3-инструмент в сторону универсальной платформы нагрузочного тестирования.

## Требования

- Java 21+;
- существующая конфигурация 2.2.2 сохраняется;
- Coordinator и Agent рекомендуется обновлять совместно;
- перед обновлением сохранить резервную копию JAR, bootstrap-конфигурации и PostgreSQL;
- для интеграции ClickHouse подготовить HTTP(S) endpoint и отдельного пользователя с минимально необходимыми правами.

## Обновление

1. Остановить Coordinator и Agents.
2. Заменить JAR на `evo-snt-s3-2.2.3-rc1.jar` либо использовать Docker image с тегом `2.2.3-rc1`.
3. Запустить Coordinator, дождаться Flyway V9–V13 и проверить readiness.
4. Запустить Agents и проверить регистрацию/heartbeat.
5. Выполнить существующий локальный и распределённый S3-тест для контроля обратной совместимости.
6. Создать ClickHouse profile в `/settings/clickhouse-profiles`, проверить соединение и discovery.
7. Выполнить короткий `INSERT`/`SELECT` тест на специально выделенной тестовой таблице.

## Миграции PostgreSQL

Обновление добавляет таблицы ClickHouse через Flyway V9–V13. Существующие таблицы и S3-профили не удаляются. Не запускайте старый Coordinator 2.2.2 после применения миграций без предварительной проверки совместимости и резервной копии.

## Проверка после обновления

Проверьте:

- `/actuator/health/readiness` и `/api/health/overview`;
- доступ к существующим S3-профилям, истории и расписаниям;
- регистрацию и heartbeat Agents;
- создание и discovery ClickHouse profile;
- локальный и распределённый ClickHouse-тест;
- `/clickhouse/replication` и `/clickhouse/ha` для replicated-кластера.

Для failover-сценария используйте только тестовый кластер. Приложение не останавливает и не запускает реплики самостоятельно: оператор вносит отказ и подтверждает этапы в UI.

## Откат

1. Остановить Coordinator и Agents.
2. Восстановить PostgreSQL из резервной копии, сделанной до применения V9–V13.
3. Вернуть JAR/Docker image 2.2.2 и предыдущую bootstrap-конфигурацию.
4. Запустить Coordinator, затем Agents, и повторить readiness/S3 smoke test.

Удаление новых таблиц вручную не считается поддерживаемым откатом.
