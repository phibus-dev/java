# Evaluation guide — 2.3.0-rc5

1. Разверните 2.3.0-rc5 в тестовой среде.
2. В Keycloak для клиента `s3-perf` укажите `Valid post logout redirect URIs`: `https://s3-perf.ep-m.tn.tngrp.ru/*`.
3. Выполните вход через Keycloak и убедитесь, что пользователь и client role отображаются в шапке.
4. Нажмите «Выйти»: локальная сессия и сессия Keycloak должны завершиться без сообщения об ошибке CSRF.
5. После logout должен произойти возврат на внешний HTTPS URL приложения.
6. Проверьте главную страницу на типовом рабочем разрешении и на ширине около 900 px: карточки, hero-блок, ссылки и пользовательское меню не должны выходить за границы экрана.
7. Проверьте `/settings/s3-profiles`: корпоративный UI, breadcrumbs, создание/удаление/назначение default profile.
8. Выполните smoke-test S3, ClickHouse, Monitoring и Settings.
