# ЭВО.СНТ S3 2.3.0-rc2 — UX Preview

Исправляющий release candidate UX Preview.

## Исправления относительно rc1

- устранён HTTP 500 при открытии титульной страницы `/`;
- устранён конфликт Spring MVC `Ambiguous handler methods mapped for '/'`;
- корневой маршрут `/` теперь однозначно обслуживается новой титульной страницей;
- страница запуска S3-тестов доступна по `/tasks`.

## UX Preview

Сохраняются изменения 2.3.0-rc1: титульная страница, навигация, пользовательская панель и выход, favicon/web manifest, breadcrumbs, поиск по истории, toast-уведомления, role-aware UI, состояние сервисов и варианты UI A/B/C/D.

Версия предназначена для тестирования UX перед включением изменений в стабильную линию 2.3.0.
