# ЭВО.СНТ S3 2.2.2

Стабильный релиз ветки 2.2.2, подготовленный на основе успешно протестированной версии 2.2.2-rc4. Функциональный код относительно проверенного RC4 не изменяется.

## Основные изменения

### Распределённое нагрузочное тестирование

- реализован режим координатора и агентов для распределённых S3-тестов;
- добавлена регистрация агентов с использованием registration token;
- реализованы heartbeat и контроль доступности агентов;
- добавлен выбор доступных агентов для распределённого задания;
- OFFLINE и DISABLED агенты исключаются из выбора для запуска теста;
- реализован запуск распределённых заданий и получение агрегированных результатов;
- добавлена страница управления агентами и интерфейс распределённых тестов.

### Стабилизация agent API

- исправлена CSRF-защита машинных API регистрации/heartbeat агента: token-authenticated agent endpoints больше не требуют browser CSRF token;
- исправлен HTTP 500 при `GET /api/agents`, если агент зарегистрирован без `name`;
- исправлен HTTP 500 при heartbeat агента без имени;
- сортировка `AgentRegistry.list()` сделана null-safe;
- добавлены regression-тесты для регистрации, получения списка и heartbeat агента без имени.

### Web UI и сохранённые задания

- исправлена автоматическая подстановка параметров сохранённого задания в форму теста;
- улучшены состояния загрузки и обработка ошибок страницы `/distributed-tests`;
- добавлены timeout для API-запросов;
- улучшено отображение ошибок взаимодействия с координатором и агентами.

### Графики и наблюдаемость

- расширены графики результатов и трендов производительности;
- добавлены подписи осей, сетка, шкала значений и дополнительная детализация;
- улучшена интерактивность графиков;
- сохранена поддержка Prometheus/Grafana и существующих метрик ветки 2.2.x.

### Release/CI

- исправлена подготовка prerelease assets;
- стабилизирован release workflow;
- исправлена Maven-конфигурация release-ветки;
- сохранена генерация JAR, source/javadoc artifacts, SBOM и checksums согласно release workflow.

## Совместимость

- Java 21+;
- существующая конфигурация 2.2.x сохраняется;
- координатор и агенты рекомендуется запускать на одной версии 2.2.2;
- существующие локальные S3-тесты продолжают поддерживаться наряду с распределённым режимом.

## Проверено перед выпуском

На версии 2.2.2-rc4 выполнено функциональное тестирование распределённого режима: регистрация агентов, heartbeat, получение списка агентов и выполнение распределённых тестов работают корректно. Stable 2.2.2 подготовлен из этого проверенного состояния без функциональных изменений.

## Статус

Версия 2.2.2 является стабильным релизом и заменяет release candidates 2.2.2-rc1 — 2.2.2-rc4 для эксплуатационного использования.
