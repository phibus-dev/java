# ЭВО.СНТ S3 2.3.0-rc5 — UX Preview

Исправляющий release candidate UX Preview.

## Исправления относительно rc4

- исправлен logout: CSRF-токен теперь выдаётся сервером вместе с `/api/session` и используется в обычном POST `/logout`;
- устранена ошибка «Не удалось получить CSRF-токен для выхода»;
- сохранён OIDC logout через Keycloak с `OidcClientInitiatedLogoutSuccessHandler`;
- улучшена адаптивная разметка главной страницы: карточки, ссылки, hero-блок и пользовательское меню приведены к единому корпоративному UI;
- устранены визуальные несоответствия стандартных ссылок и потенциальное горизонтальное переполнение на узких экранах;
- сохранены исправления RC4 для страницы профилей S3 и HTTPS reverse proxy.

## Keycloak

Для корректного возврата после logout в клиенте `s3-perf` должен быть разрешён post logout redirect URI, например:
`https://s3-perf.ep-m.tn.tngrp.ru/*`.
