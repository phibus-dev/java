# Upgrade / test guide — 2.4.0-rc5

1. Разверните JAR или Docker image 2.4.0-rc5 поверх rc4.
2. Миграций БД относительно rc4 нет.
3. Войдите под ролью `OPERATOR` и откройте Kafka Producer.
4. Выберите сохранённый Kafka Profile и нажмите «Проверить подключение» — запрос `/api/kafka/profiles/{id}/check` не должен возвращать HTTP 403.
5. Повторите проверку под `ADMIN`.
6. Убедитесь, что `OPERATOR` по-прежнему не может создавать, изменять, удалять и назначать Kafka-профили по умолчанию.
7. Проверьте источники credentials `PLAIN`, `ENVIRONMENT`, `VAULT` для SASL-профилей.
8. После успешной проверки подключения выполните короткий Producer Load Test и убедитесь, что runtime-метрики обновляются.
