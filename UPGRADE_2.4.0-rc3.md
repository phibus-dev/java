# Upgrade / test guide — 2.4.0-rc3

1. Сделайте резервную копию PostgreSQL конфигурационной БД приложения.
2. Разверните JAR или Docker image 2.4.0-rc3.
3. При обновлении с rc2 новых DB migration относительно rc2 нет; должны быть применены Kafka migrations V16-V20.
4. Откройте Настройки → Профили Kafka.
5. Создайте или измените Kafka Profile и нажмите «Сохранить».
6. Не обновляя страницу, нажмите «Проверить подключение» — профиль должен остаться выбранным и проверка должна выполняться без сообщения «Сначала сохраните профиль».
7. Для существующего профиля нажмите «Изменить», затем «Проверить подключение».
8. Проверьте операции назначения профиля по умолчанию и удаления — HTTP 403 быть не должно.
9. Для SASL можно использовать NONE, PROFILE, VAULT или ENVIRONMENT. Для PROFILE задайте S3_PERF_BOOTSTRAP_KEY.
10. Выполните Producer, Consumer/E2E, KRaft/Replication и Failover acceptance tests.

Подробные критерии: `KAFKA_M3_ACCEPTANCE.md` и `KAFKA_M4_ACCEPTANCE.md`.
