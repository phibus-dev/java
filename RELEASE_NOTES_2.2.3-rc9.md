# ЭВО.СНТ 2.2.3-rc9

## Исправления

- Новый переключаемый корпоративный UI A/B/C/D теперь применяется к странице настроек Keycloak.
- `keycloak-settings.html` переведён с автономных встроенных стилей на общие `app.css` и `app-ui.css`.
- Выбранный режим представления сохраняется при переходе между основными настройками и Keycloak благодаря общему `localStorage`-ключу UI.
- Страница Keycloak получила общий корпоративный header, навигацию, панели и диагностический блок в стилистике остальных разделов приложения.
