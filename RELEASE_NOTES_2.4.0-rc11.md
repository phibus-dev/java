# ЭВО.СНТ S3 2.4.0-rc11

Одиннадцатый release candidate версии 2.4.0.

## Изменения относительно rc10

### Единая навигация
- на всех страницах добавлена единообразная шапка в стиле главной страницы;
- логотип в шапке является ссылкой на главную страницу;
- общие элементы интерфейса подключены ко всем HTML-шаблонам.

### История заданий
- задания отображаются построчно в таблицах;
- размер страницы истории закреплён на 10 записях;
- для динамических таблиц истории добавлена клиентская пагинация по 10 записей;
- поиск по истории совместим с пагинацией.

### Kafka UI
- раздел `Consumer & E2E` переименован в `Consumer\Throughput`;
- тест `Producer -> Consumer E2E` переименован в `Producer -> Consumer`;
- блок `E2E Runtime / Consistency` переименован в `Runtime results`.

### Kafka M3 Replication и Partition Scaling
- сервер возвращает фактическую первопричину ошибки запуска вместо общего ответа `500 Internal Server Error`;
- причина ошибки отображается непосредственно в блоке Replication Test;
- ошибки постановки задания в executor фиксируются как завершённый результат `FAILED`;
- исключено сохранение задания в состоянии `RUNNING` при отказе планирования;
- полный stack trace серверной ошибки записывается в журнал приложения;
- добавлены тесты серверной диагностики и отображения ошибки в UI.

## Совместимость

Новых миграций БД относительно rc10 нет. Конфигурация Kafka-профилей и результаты предыдущих запусков сохраняются.
