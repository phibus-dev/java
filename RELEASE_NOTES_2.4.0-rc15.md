# ЭВО.СНТ S3 2.4.0-rc15

Пятнадцатый release candidate версии 2.4.0.

## Изменения относительно rc14

### Метрики и операции S3
- для multipart upload одна операция определяется как один запрос `UploadPart`;
- перцентили p50/p95/p99 рассчитываются по накопительной потокобезопасной HDR-гистограмме;
- отдельно сохраняется ограниченное окно последних операций;
- неуспешные SDK-запросы учитываются в количестве операций, ошибках и задержках;
- расчёт времени переведён на монотонные часы, добавлена скользящая скорость за последние две секунды;
- объём детальных результатов и число завершённых прогонов ограничены для защиты памяти;
- отменённые и завершённые прогоны не принимают запоздалые результаты.

### История и повторный запуск
- добавлена миграция БД V23;
- результаты длительных тестов сохраняются с последовательным номером без потери повторяющихся object/part;
- счётчики операций в PostgreSQL переведены на `BIGINT`;
- сохраняются параметры workload/profile, необходимые для точного повторного запуска;
- сохранённые ручные S3-ключи удаляются из расписаний.

### ClickHouse и Kafka
- число ClickHouse-запросов отделено от числа прочитанных или записанных строк;
- SELECT выполняется заданное число раз, прогресс рассчитывается по количеству запросов;
- неоднозначный `INSERT_SELECT` в режиме duration отклоняется проверкой параметров;
- Kafka target rate применяется глобально ко всем worker-потокам;
- в runtime-метриках Kafka сохраняются повторные попытки отправки.

### Распределённое выполнение и безопасность
- резервирование агентов сделано атомарным, добавлен откат резерва при ошибке запуска;
- исправлены HTTP-коды протокола агентов и обработка переполнения executor;
- identity-файл агента создаётся атомарно с правами `0600`;
- токен повторного запуска обновляется;
- временные AWS credentials поддерживают session token;
- S3-ключи исключены из расписаний и распределённых payload;
- усилено разделение прав `VIEWER`, `OPERATOR` и `ADMIN`.

### Проверки качества
- 126 unit-тестов и 5 интеграционных тестов;
- интеграционные проверки миграций PostgreSQL и S3-совместимости;
- SpotBugs: 0 замечаний;
- формируются исполняемый JAR, source/javadoc JAR, CycloneDX SBOM и SHA-256 checksums.

## Совместимость

Релиз содержит миграцию V23. Перед обновлением необходимо создать резервную копию PostgreSQL. Координатор и все agent JAR следует обновить одновременно. Агенты должны получать S3 credentials из локального профиля, переменных окружения или Vault; передача ручных ключей из координатора больше не поддерживается.
