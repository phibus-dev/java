# Обновление до ЭВО.СНТ S3 2.2.3-rc11

## Назначение обновления

RC11 исправляет 403 Forbidden на действиях «Проверить подключение» и «Сохранить» в настройках Keycloak.

## Обновление

1. Остановите текущий экземпляр приложения.
2. Замените JAR или Docker image на версию `2.2.3-rc11`.
3. Сохраните существующий bootstrap configuration и значение `S3_PERF_BOOTSTRAP_KEY`.
4. Запустите приложение.
5. Откройте «Настройки → Keycloak» и выполните «Проверить подключение».
6. Убедитесь, что запрос больше не возвращает HTTP 403 и отображается результат проверки Keycloak.
7. Выполните «Сохранить» и убедитесь, что настройки сохраняются без CSRF-ошибки.

Изменений схемы PostgreSQL относительно RC10 нет.
