# Обновление до ЭВО.СНТ S3 2.2.2-rc2

Это промежуточный тестовый релиз для проверки исправления PR #75.

## Требования

- Java 21+;
- существующая конфигурация 2.2.1 и 2.2.2-rc1 совместима;
- миграции PostgreSQL не требуются;
- изменения `bootstrap-settings.json` не требуются.

## Обновление JAR

1. Остановить приложение.
2. Сохранить резервную копию текущего JAR.
3. Установить `evo-snt-s3-2.2.2-rc2.jar`.
4. Запустить приложение с прежней конфигурацией.
5. Проверить `/actuator/health/readiness`.
6. Открыть `/distributed-tests` и выполнить функциональную проверку распределённого запуска.

## Обновление Docker

Используйте prerelease image с точным тегом:

```text
ghcr.io/phibus-dev/s3-performance-test-web:2.2.2-rc2
```

Не используйте `latest` для проверки prerelease.

## Приёмочная проверка PR #75

- список агентов не остаётся в состоянии `Загрузка…`;
- история распределённых запусков не остаётся в состоянии `Загрузка…`;
- при отсутствии агентов отображается явное пустое состояние;
- при недоступном API ошибка появляется не позднее 10 секунд;
- создание распределённого теста работает с CSRF-защитой;
- периодическое обновление истории работает после успешного запуска;
- в Console отсутствуют ошибки CSP для `/distributed-tests`.

## Откат

Для отката остановите приложение и верните JAR или Docker image версии `2.2.1` либо предыдущего тестового `2.2.2-rc1`. Изменения схемы данных отсутствуют, дополнительный rollback не требуется.
