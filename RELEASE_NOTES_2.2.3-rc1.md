# ЭВО.СНТ Performance 2.2.3-rc1

Первый release candidate ветки 2.2.3. Версия открывает переход от специализированного S3-инструмента к расширяемой платформе нагрузочного тестирования с подключаемыми test engines.

## Основное направление

- сохранение полной совместимости существующих S3-тестов;
- выделение универсального API движков нагрузочного тестирования;
- подготовка архитектуры для второго движка — ClickHouse;
- дальнейшая поддержка сценариев ClickHouse MergeTree и семейства Replicated*;
- сохранение общей инфраструктуры Coordinator/Agent, history, scheduler, trends, reports, Prometheus/Grafana и security.

## План 2.2.3-rc1

Первый этап — PR 97: универсальный LoadTestEngine API и адаптация текущего S3 engine без изменения пользовательского поведения.

Дальнейшие PR добавят ClickHouse profiles, базовые INSERT/SELECT тесты, UI/history, distributed execution и специализированные сценарии ReplicatedMergeTree/HA.

## Статус

Версия предназначена для поэтапного тестирования архитектурных изменений. До завершения ClickHouse MVP существующий S3-функционал должен оставаться обратно совместимым с 2.2.2.
