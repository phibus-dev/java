# ЭВО.СНТ S3 2.3.0-rc1 — UX Preview

Тестовый release candidate для оценки UX-доработок, описанных в `UX_PREVIEW_2.3.0.md`. Не предназначен для продуктивного использования до завершения оценки.

## Что включено

- новая титульная страница `/` с навигацией и обзором сервиса;
- глобальная пользовательская панель с логином, ролью, версией и кнопкой выхода;
- favicon и web manifest;
- breadcrumbs;
- глобальный поиск по истории;
- toast-уведомления;
- базовый role-aware UI для ADMIN / OPERATOR / VIEWER;
- блок состояния системы без ложного отображения неподключённых сервисов как OK;
- быстрые переходы к S3, ClickHouse, Agents и Monitoring;
- информация о версии и времени запуска;
- сохранены варианты UI A/B/C/D.

## Назначение RC

Версия предназначена для визуальной и функциональной оценки применимости UX Preview перед включением изменений в стабильную линию 2.3.0.
