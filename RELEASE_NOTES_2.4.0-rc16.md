# ЭВО.СНТ S3 2.4.0-rc16

Шестнадцатый release candidate версии 2.4.0.

## Изменения относительно rc15

### Единый пользовательский интерфейс

- все 31 серверные страницы переведены на общий Thymeleaf-каркас заголовка, основной и контекстной навигации, подключаемых ресурсов и подвала;
- унифицированы названия разделов, активные состояния, breadcrumbs, заголовки страниц, таблицы, формы и адаптивное оформление;
- удалены конфликтующие UI-режимы и повторное подключение CSS;
- глобальный поиск передаёт поддерживаемый сервером параметр `q`;
- сохранена карточка Kafka на главной странице;
- удалены устаревшие статические дубликаты страниц аудита и расписаний.

### Доступность и безопасность интерфейса

- действия интерфейса согласованы с ролями `VIEWER`, `OPERATOR` и `ADMIN`, включая динамически создаваемые кнопки;
- меню пользователя поддерживает состояние `aria-expanded`, закрытие клавишей Escape и безопасный вывод имени;
- таблицы получают caption и `scope=col`, добавлены единые focus-состояния;
- страница аудита переведена на безопасное формирование DOM через `textContent`;
- удалено преждевременное глобальное уведомление об успешной отправке формы до ответа сервера.

### Запуск и bootstrap-режим

- исправлен критический дефект выбора конструктора `UploadTestEngine`, из-за которого собранный rc15 JAR не запускался;
- общий CSS, JavaScript, логотип и `/api/session` доступны на странице первичной настройки до подключения PostgreSQL;
- плановый сборщик ClickHouse не обращается к БД до перехода приложения в состояние `READY`;
- недоступность PostgreSQL больше не приводит к повторяющимся stack trace плановой задачи в bootstrap-режиме.

### Проверки качества

- 141 unit-тест и 5 интеграционных тестов завершены успешно;
- добавлен тест запуска полного Spring-контекста;
- добавлены регрессионные тесты общего UI, bootstrap assets, ролей, аудита и ClickHouse sampler;
- SpotBugs: 0 замечаний;
- собранный GitHub Actions JAR проверен отдельным smoke-тестом в bootstrap-режиме.

## Совместимость

Новых миграций БД нет. Формат bootstrap-конфигурации и протокол агентов не изменены. Рекомендуется обновить координатор и все agent JAR до rc16, поскольку исправление запуска `UploadTestEngine` относится к обоим режимам приложения.
